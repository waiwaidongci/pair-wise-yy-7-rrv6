# 古船模型帆索校准

运行：

```bash
npm start
```

访问 `http://localhost:3038`。数据保存在 `data/model-rigging-calibration.json`。

## 业务文件划分

| 文件 | 职责 |
| --- | --- |
| `rules.js` | 规则：任务状态、材料领用幂等、批次余量/过期/材料校验、实际用量与剩余线头结算、未结领用阻止完成 |
| `store.js` | 存储：JSON 读写、种子批次、旧数据迁移、基础查找 |
| `page.js` | 页面：批次台账、领用/结算/退回核对界面与浏览器脚本 |
| `server.js` | HTTP 路由装配，把规则结果映射为接口响应 |

## 材料领退规则

- 领用按帆索任务选择**材料批次**并登记**领用长度(cm)**；同一 `申请编号` 重复提交只落一次（返回首条记录）。
- 批次材料与帆索材料不符、批次已过期或批次余量不足：领用停在**待处理**并写明原因，不扣减批次余量。
- 正常领用状态为**已领用**，同时扣减批次余量。
- 调整结束登记**实际用量**与**剩余线头**：用量不得超过领用长度，二者合计与领用长度的差额须在剪线损耗（0.01cm）以内；超范围可登记为**退回核对**，线头不回库。
- 正常结算后剩余线头回入批次余量；存在**已领用/退回核对**的未结领用时，任务不能确认完成（仅“待处理”不阻止）。
