# 古船模型帆索校准

运行：

```bash
npm start
```

访问`http://localhost:3038`。数据保存在`data/model-rigging-calibration.json`。

## 结构

- `server.js`：HTTP 路由入口
- `rules.js`：业务规则（材料领退、结算、任务完成校验）
- `store.js`：数据存储与迁移
- `page.js`：页面

## 材料领退

- 按帆索任务选择材料批次并登记领用长度；同一申请编号重复提交只落一次，不重复扣减库存。
- 余量不足或批次过期的申请停在「待处理」并写明原因，可撤销后换新申请编号重新登记。
- 调整结束登记实际用量和剩余线头：与领用长度对账超差（±0.1 米）即「退回核对」，核对范围内「已结算」并把线头退回批次库存。
- 任务存在未结领用（待处理 / 已领用 / 退回核对）时不能确认「已完成」。
